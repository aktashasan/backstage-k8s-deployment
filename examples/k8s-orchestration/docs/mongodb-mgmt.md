# MongoDB Management

MongoDB database management mikroservisi.

## Açıklama

MongoDB instance'larını provision etmek ve yönetmek için kullanılan mikroservis.

## Teknoloji

- **Framework**: NestJS
- **Language**: TypeScript/Node.js
- **API**: GraphQL
- **Database**: MongoDB

## Özellikler

- MongoDB instance provisioning
- Database lifecycle management
- Connection management
- Backup/restore operations
