# Cloud Account Management

Cloud account management mikroservisi - AWS, Azure, GCP cloud hesaplarını yönetir.

## Açıklama

Çoklu bulut sağlayıcı (AWS, Azure, GCP) hesaplarını yönetmek için kullanılan mikroservis.

## Teknoloji

- **Framework**: NestJS
- **Language**: TypeScript/Node.js
- **API**: GraphQL
- **Database**: PostgreSQL

## Özellikler

- AWS account yönetimi
- Azure account yönetimi
- GCP account yönetimi
- Cloud credential management
