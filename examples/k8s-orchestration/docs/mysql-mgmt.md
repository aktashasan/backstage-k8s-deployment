# MySQL Management

MySQL database management mikroservisi.

## Açıklama

MySQL instance'larını provision etmek ve yönetmek için kullanılan mikroservis.

## Teknoloji

- **Framework**: NestJS
- **Language**: TypeScript/Node.js
- **API**: GraphQL
- **Database**: PostgreSQL

## Özellikler

- MySQL instance provisioning
- Database lifecycle management
- Connection management
- Backup/restore operations

- **Kubernetes Namespace**: `crystal`
- **Port**: 3000
