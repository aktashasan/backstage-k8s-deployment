# PostgreSQL Management

PostgreSQL database management mikroservisi.

## Açıklama

PostgreSQL instance'larını provision etmek ve yönetmek için kullanılan mikroservis.

## Teknoloji

- **Framework**: NestJS
- **Language**: TypeScript/Node.js
- **API**: GraphQL
- **Database**: PostgreSQL

## Özellikler

- PostgreSQL instance provisioning
- Database lifecycle management
- Connection pooling
- Backup/restore operations

- **Kubernetes Namespace**: `crystal`
- **Port**: 3000
