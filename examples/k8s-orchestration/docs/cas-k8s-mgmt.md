# CAS Kubernetes Management

CAS (Container as a Service) Kubernetes cluster management mikroservisi.

## Açıklama

Kubernetes cluster'larını yönetmek için kullanılan CAS platform mikroservisi.

## Teknoloji

- **Framework**: NestJS
- **Language**: TypeScript/Node.js
- **API**: GraphQL
- **Database**: PostgreSQL

## Özellikler

- Kubernetes cluster yönetimi
- CAS platform entegrasyonu
- Cluster lifecycle management
