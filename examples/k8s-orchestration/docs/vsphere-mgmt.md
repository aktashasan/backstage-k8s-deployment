# vSphere Management

vSphere infrastructure management mikroservisi.

## Açıklama

VMware vSphere altyapısını yönetmek için kullanılan mikroservis. Virtual machine ve resource yönetimi sağlar.

## Teknoloji

- **Framework**: NestJS
- **Language**: TypeScript/Node.js
- **API**: GraphQL
- **Database**: PostgreSQL

## Özellikler

- Virtual machine yönetimi
- vSphere resource management
- Template management
- Storage policy management
