# MinIO Management

MinIO object storage management mikroservisi.

## Açıklama

S3-compatible object storage provisioning için kullanılan mikroservis.

## Teknoloji

- **Framework**: NestJS
- **Language**: TypeScript/Node.js
- **API**: GraphQL
- **Database**: PostgreSQL

## Özellikler

- MinIO instance provisioning
- S3-compatible storage management
- Bucket management
- Access key management
